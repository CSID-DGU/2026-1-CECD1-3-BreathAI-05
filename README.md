# 2026-1-CECD1-3-BreathAI-05

### BreathAI

> AI 기반 챗봇 학습데이터 현행화 지원 시스템

서울교통공사 챗봇(또타24)의 미답변 로그를 AI로 분석하여 신규 FAQ 후보 및 키워드 확장안을 자동 도출하고, 운영자가 검토·반영할 수 있는 체계를 구축합니다.

## 팀원

| 이름 | 역할 |
|------|------|
| 모주현 | Data/AI |
| 김시환 | AI Server |
| 박서연 | Backend |
| 오유진 | Frontend |

## 기술 스택

- **Frontend**: React, TypeScript
- **Backend**: Spring Boot (Java)
- **AI Server**: FastAPI (Python)
- **Database**: MariaDB
